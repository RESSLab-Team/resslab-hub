# Archive

Old plans, design notes and review notes, kept for the history of the project.
They are not part of the docs site, and they are not kept up to date: a page here
can be wrong about the code of today. Read the code or the guides in `docs/` first.

- `modernization-followups.md`: the toolchain work of 2026 and what was still open.
- `design/`: the brand exploration and the brief of the sign-in email.
- `review/`: the review of sign-in, roles and contributions of November 2026, with its findings.
